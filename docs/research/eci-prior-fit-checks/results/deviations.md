# Deviations from the plan

Each entry: what changed, why, its effect. No registered threshold or rule was changed.

1. **Sampler for our models (M12).** The plan says our models are sampled by our own NUTS call. On the owner's instruction F0 uses Epoch's own sampling routine: `fit_bayesian_eci` is called with `eci.bayesian.build_bayesian_model` replaced in memory by our builder (pilot with a diagonal mass matrix, then a dense mass matrix, Epoch's draw ladder and cold fallback). For expansions and PR the same call is used with `_FREE_VARS` and `_DIAGNOSTIC_VARS` extended in memory for the added variables. Effect: EQ tests the same sampler on both sides, so a fit difference can only come from the model; expansion fits use the pilot and dense stages, which Epoch's README says are about ten times cheaper per effective sample than the cold stage.
2. **Misfit replicate positions (M4).** "As G-null" does not say which posterior draw a misfit replicate uses. Replicate $r$ of a generator with $R_g$ replicates uses the pooled draw at position floor(r S / R_g) (199 for G-null, 20 for each misfit generator), so the 20 misfit replicates spread over all chains instead of clustering in the first draws.
3. **K-fold folds from Epoch's code (M14).** See the W6 entry when written.
4. **Normalised Jeffreys priors J1 and J2 (post-freeze, exploratory, user-requested; Revision Log R26).** Two new arms that add a Jeffreys prior on each capability, normalised over the box, to Epoch's model (M11). They were added after the freeze at the user's request, enter no gate and no confirmatory verdict, and change no registered threshold, rule or grid entry. They replace a first, unnormalised form J, which was rejected because its joint prior is not normalisable in the slope scale (`W/W1J/summary_J_first_form.md`). `prior-grid.json` gained the key `jeffreys_priors_exploratory`; its other contents are unchanged, so the digest recorded for the file before the freeze no longer matches it. Effect: none on C1 to C3.
5. **Numerical choices for J1 and J2.** The trigamma function is our own differentiable implementation (recurrence to an argument of at least 7, then the asymptotic series; relative error at most $2\times10^{-14}$ against `scipy.special.polygamma`), not PyTensor's `tri_gamma`, whose gradient works but runs in Python object mode and is about 100 times slower. The normalising integral $Z_m$ is a fixed-node Gauss-Legendre rule, accurate to better than $10^{-6}$ for difficulties within about $\pm 16$ and slopes up to about 6. The information ignores the clipping of $y$ in the Beta likelihood. W1 for J1 and J2 is by direct simulation, because NUTS on Epoch's box prior diverges at every iteration even without a potential. Effect: the potentials agree with independent numpy and scipy computations to about $10^{-12}$ (`W/W1J/checks_normalised.json`).
6. **Additional rank tests and predictive graphics (R29, post-freeze, reported only).** Rank tests with the joint log-likelihood and residual quantities as test quantities (M13: `runs/lib/sbc_modrak.py`, `runs/w3_modrak.py`), an optional posterior SBC script (`runs/w5_posterior_sbc.py`, not run), and graphical checks, effect sizes and randomised LOO-PIT (M5: `runs/lib/ppc_graphics.py`, `runs/w4_graphics.py`) were added after the freeze. They read W3 and W2 outputs and enter no gate or verdict. Test 1, Test 2, the SBC verdict, G1, T1 to T7 and the C2 decision rule are unchanged, and the frozen files `sbc.py` and `ppc_checks.py` are only imported.
7. **Interim analyses while W3 runs.** The first runs of the new scripts (`W/W3M/`, `W/W4G/`) used the G-null replicates finished at that time (22 of 199), so every calibrated p-value in them is interim and cannot reject. They read `W/W3/` files only and wrote nothing there. The regenerated simulated data match the stored statistics T1 to T7 exactly (maximum relative difference 0 on replicate null_0), which is the check that the simulated scores can be recomputed without storing them.
8. **Truth from the posterior (caveat, not a change).** W3 draws the true parameters from the W2 posterior and refits on the simulated data alone, so its ranks are not exactly uniform when everything is correct (M13, `W/W3M/selftest.json`). The posterior SBC (refit on observed and simulated data) is the exactly calibrated version and is optional after W5.
